## Preview locally
Open `index.html` in a browser. If needed, run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Free hosting with GitHub Pages
1. Sign in at https://github.com.
2. Create a public repository such as `sanchita-qa-portfolio`.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root.
4. Go to **Settings → Pages**.
5. Under build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, and save.
6. After GitHub Pages deploys, your URL will resemble `https://YOUR-USERNAME.github.io/sanchita-qa-portfolio/`.
7. Replace `YOUR-USERNAME` with your GitHub username and test all links.
